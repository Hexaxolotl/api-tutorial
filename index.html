Status Codes

I learned that a status code tells me how the API request went.
The picture above shows a status code of 200, this means the request was successful.

API keys belong in headers

I learned some APIs need an API key before they will return the requested information. Without the API key I got an 400 status code, showing a "error: missing API key".

After adding the API key to the x-api-key header, I was able to resovle this status code.
